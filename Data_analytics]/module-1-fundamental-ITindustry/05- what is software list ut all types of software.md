# What Is Software?

**Software** is the set of programs, instructions, and related data that tells a computer or digital device what to do. Unlike hardware, software is not a physical component. It runs on hardware such as computers, phones, servers, and embedded devices.

There is no single exhaustive list of software types. Software can be classified by its purpose, how it runs, or how it is distributed. The categories below are common and can overlap—for example, a web browser is both application software and end-user software.

## Main Types by Purpose

- **System software** — Runs and manages a computer and provides a foundation for other software.
  - **Operating systems (OS)** — Manage hardware, files, memory, processes, and user interaction. *Examples: Windows, macOS, Linux, Android, iOS.*
  - **Device drivers** — Help the operating system communicate with hardware such as printers, graphics cards, and keyboards.
  - **Utility software** — Helps maintain, protect, or manage a device. *Examples: backup tools, antivirus software, disk-management tools, and file-compression utilities.*
- **Application software** — Helps users perform specific tasks. *Examples: word processors, spreadsheets, web browsers, media players, design tools, and mobile apps.*
- **Programming and development software** — Helps people create, test, debug, and maintain software. *Examples: code editors, compilers, interpreters, debuggers, and integrated development environments (IDEs).*
- **Middleware** — Connects applications, services, or systems so they can exchange data or work together. *Examples: application servers, message brokers, and database connectivity software.*
- **Firmware** — Software stored in or closely associated with a device's hardware that controls its basic operation. *Examples: firmware in routers, cameras, and computer components.*

## Other Common Categories

- **Embedded software** — Software built into a device to perform a dedicated function. It often runs on a microcontroller or specialized computer. *Examples: software in washing machines, vehicle control units, and smart devices.*
- **Web software** — Software accessed through a web browser, often from a remote server. *Examples: online banking, webmail, and web-based project tools.*
- **Database software** — Stores, organizes, retrieves, or manages data. *Examples: relational database management systems and document databases.*
- **Enterprise software** — Supports processes across an organization. *Examples: customer relationship management (CRM), enterprise resource planning (ERP), and human resources systems.*
- **Scientific and engineering software** — Supports specialized analysis, design, simulation, and research. *Examples: statistical tools, computer-aided design (CAD), and simulation software.*
- **Artificial intelligence and machine-learning software** — Uses algorithms and models to perform tasks such as classification, prediction, or language processing.
- **Security software** — Helps protect devices, networks, accounts, or data. *Examples: firewalls, endpoint protection, and password managers.*
- **Communication and collaboration software** — Helps people exchange messages and work together. *Examples: email, video conferencing, and shared-workspace tools.*
- **Entertainment software** — Provides games and other interactive or media experiences. *Examples: video games and streaming applications.*

## Categories by How Software Is Distributed or Used

- **Desktop software** — Installed and run on a personal computer.
- **Mobile software** — Designed for phones or tablets.
- **Cloud-based software** — Runs partly or mainly on remote servers and is accessed over a network.
- **Open-source software** — Makes its source code available under a license that allows specified uses, modification, or redistribution.
- **Proprietary software** — Distributed under terms that restrict access to or use of its source code.
- **Freeware** — Available to use without charge, but it may still be proprietary.
- **Shareware or trial software** — Offered for evaluation, often with time, feature, or usage limits.

These labels describe different aspects of software: for example, an application can be mobile, cloud-based, open-source, or proprietary.
