# What Is Web Hosting?

**Web hosting** is a service that stores a website or web application on a computer called a **server** and makes it available over the internet. Hosting providers supply some combination of server resources, network connectivity, storage, security, backups, and management tools.

When someone visits a website, their browser connects to the server and requests the site's files or data. The server sends back the content for the browser to display.

There is no single exhaustive list of hosting types: providers combine different technologies and services. The following are common hosting models and related options.

## Hosting Types by Server Arrangement

- **Shared hosting** — Many websites share one server and its resources. It is usually affordable and easy to use, but performance and configuration options may be limited.
- **VPS (Virtual Private Server) hosting** — One physical server is divided into virtual servers. Each customer gets allocated resources and more control than with shared hosting, though the underlying hardware is shared.
- **Dedicated server hosting** — A customer rents an entire physical server. It offers substantial control and resources, but generally costs more and may require server-management skills.
- **Cloud hosting** — A website runs on virtual resources drawn from a cluster or pool of connected servers. It can scale more flexibly than a single-server setup; cost and configuration depend on the provider.
- **Colocation hosting** — A customer owns the physical server but places it in a data center, which supplies space, power, cooling, and network connectivity. The customer remains responsible for the server hardware and usually its software.
- **Self-hosting (on-premises hosting)** — An organization runs its own server on its own premises or infrastructure. It offers direct control but requires the organization to manage connectivity, power, security, maintenance, and availability.

## Hosting Types by Management or Platform

- **Managed hosting** — The provider handles some server administration, such as updates, monitoring, backups, or security. The exact services vary, so check the plan's scope.
- **Unmanaged hosting** — The provider supplies the server or virtual machine, while the customer handles most software setup, updates, security, and maintenance.
- **WordPress hosting** — A hosting plan configured for WordPress sites. It may be shared, VPS, or cloud-based, and may be managed or unmanaged.
- **Reseller hosting** — A customer buys hosting resources and resells them to their own clients, often under their own brand.
- **Container hosting** — Applications run in isolated containers, often managed with a container platform or orchestration system. It can be provided on cloud, VPS, or dedicated infrastructure.
- **Platform as a Service (PaaS)** — A platform provider manages much of the underlying infrastructure and runtime so developers can deploy applications without administering a full server.
- **Serverless or Function as a Service (FaaS)** — The provider runs code in response to events or requests and manages the servers. Despite the name, servers still exist; customers typically pay according to usage.
- **Static site hosting** — Serves prebuilt files such as HTML, CSS, JavaScript, and images. It is often simple and cost-effective for sites that do not need server-side processing.

## Hosting Types by Intended Use

- **Web or application hosting** — Runs websites, APIs, or web applications.
- **Email hosting** — Provides email accounts and mail services for a domain; it may be separate from website hosting.
- **Database hosting** — Provides a database service for applications, sometimes as a managed service.
- **Game server hosting** — Runs online multiplayer game servers.
- **Media or streaming hosting** — Stores or delivers audio and video, often using a content delivery network (CDN).
- **File hosting** — Stores files and makes them available for download or sharing.

## Quick Comparison

| Type | Typical fit | Main trade-off |
|---|---|---|
| Shared | Small sites, personal projects, and early-stage websites | Low cost, but resources are shared |
| VPS | Growing sites needing more control | More configuration and administration |
| Dedicated | High-demand or specialized workloads | High cost and greater management responsibility |
| Cloud | Workloads needing flexible capacity | Configuration and costs can be more complex |
| Managed | Owners who want the provider to handle server tasks | Less direct control and plan-dependent services |
| PaaS/serverless | Developers focused on deploying application code | Platform constraints and provider-specific behavior |

## Choosing a Hosting Type

Consider expected traffic, performance needs, budget, technical skills, security requirements, backup and support needs, and how easily resources must scale. A domain name is the website's address; hosting is the service that runs or serves its content. They are related, but they are not the same thing.
